# Security Policy

## Supported versions

Only the latest release of `exptrail` on PyPI receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability
reporting: go to the **Security** tab of this repository and click
**Report a vulnerability**. Do not open a public issue for security problems.

## What to expect

This is a solo-maintained project. I aim to reply on a best-effort basis
within 7 days.
